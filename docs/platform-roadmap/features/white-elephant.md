# White Elephant Feature Group

White Elephant is split into independently planned milestones. Both specifications are concepts only; gameplay details remain open for later discussions.

- [`white-elephant-setup`](white-elephant-setup.md) — create an event, organize guests, and configure pre-game rules.
- [`white-elephant-game`](white-elephant-game.md) — host a synchronized hybrid TV, host and player game.
- [`white-elephant-enhancements`](white-elephant-enhancements.md) — optional presentation and hosting capabilities after the core game.

## Agreed direction

- The future game should have a hybrid host and player experience.
- Administration should let the organizer control game rules where possible.
- Some live changes can be safe; consequential changes require validation and host confirmation; rules that reinterpret established state may need to lock after the game starts.
- No event setup, rules engine, or live game is implemented by this documentation.
